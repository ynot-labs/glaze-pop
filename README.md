## 核心特性（严格对标 GDD & 图 1 视觉基准）

1. **视觉与 60fps 性能红线**
   - 清爽冷建筑浅灰渐变舞台 `#E8EEF5 → #F5F8FC`，无地面/无桌面/无卡通白云。
   - 唯一程序化标准圆角方块（44 tris，光滑倒角法线）+ **单 Draw Call `MultiMeshInstance3D`**。
   - 轻量高光塑料 Shader（`roughness: 0.22, specular: 0.65` + Fresnel 边缘提亮 + 半球假环境光 + `0.06s` 受击白闪膨胀）。
   - **40 上限飞散碎块对象池**，零运行时 GC 卡顿；Web `index.pck` 仅 **317 KB**。

2. **四大核心玩法差异化**
   - **同色合炮（Merge-to-Fire）**：相邻 2 座同色发射器自动青白电弧合体为超级重炮（弹药相加 + 20% 奖励弹药、射速 ×1.8、2 层穿透）并立刻腾出 1 个活槽。
   - **脉冲能量核（Pulse Core）**：打通外壳或超级重炮穿透引爆模型内部金色核心，触发 **3×3×3 径向冲击波** 免费震飞周围异色块 + `0.15s` `Engine.time_scale = 0.35` 斩杀慢动作。
   - **活体魔方机关 + 6 色安全色板**：分段自转层（每清 1 炮自动旋转 90°）、磁吸合拢（掏空中间层上下“啪”地吸合）、铁链锁与双色交替炮；严格锁定 6 套高对比色板 + 可选色盲微符号模式。
   - **能量喷涂浮空岛（Paint-the-Island）**：消除方块化作光点汇入顶部进度条，过关可一键长按 2 秒用彩漆炮点亮 4 座主题浮空小岛并领取宝箱。

3. **6 个高辨识度 3D 展示关卡（全部通过 Auto-Solver 8/8 零道具通关校验）**
   - `Lv.1` 积木小机器人（教学同色合炮 + 胸口脉冲核）
   - `Lv.2` 太空火箭（图 1 基准造型：倾斜火箭 + 舷窗金色脉冲核 + 分段自转层）
   - `Lv.3` 复古游戏机（磁吸合拢 + 双核）
   - `Lv.4` 皇冠小鸭（分段自转层 + 双核）
   - `Lv.5` 像素超跑（解锁电光紫 + 铁链锁 + 双色交替炮）
   - `Lv.6` 霓虹扭蛋城堡（三核终极爽关 + 全机关齐发）
