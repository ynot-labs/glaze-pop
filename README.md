## 核心创新与硬核设计亮点

### 1. 四大高触感物理材质 × 物理建模五声音阶 ASMR
告别廉价荧光塑料感，采用移轴微缩棚拍光影（Tilt-Shift Studio）与自定义 GPU 着色器：
- **磨砂青釉陶瓷（Matte Ceramic `◎` / `✦`）**：温润釉面边缘积釉高光 + 微浮雕肌理，清脆骨瓷“叮咚”敲击音。
- **半透果冻硅胶（Soft Jelly `≈` / `▲`）**：次表面散射（SSS）暖光透射 + GPU 弹性呼吸形变；**爆裂时释放弹性波纹，自动震开相邻 1 格的黄铜卡扣锁**，彻底根除竞品“一格铁链卡死整局”的挫败感。
- **晶透棱面冰晶（Faceted Crystal `◆`）**：钻石切割平面法线高光 + 棱镜色散流光；**碎裂瞬间向内层发射一次免费折射穿透**，提前破开深层视野。
- **温润原木骨架（Warm Wood `▣`）**：三维程序化胡桃木纹与榫卯倒角；充当建筑承重柱，**抽空底部支撑后触发真实 BFS 重力坍塌（Timber Collapse）**，整片悬空屋顶轰然倾倒并免费消除！

### 2. 空间操作上限 × 防呆心流体验
- **360° 自由惯性旋转寻弱点**：发射器优先锁定当前朝向镜头的暴露体素，玩家可主动旋转工作台瞄准底层【胡桃木承重柱】完成定向爆破；若闲置未转，自动启动柔和寻靶扫描防止卡手。
- **S.P.A.R.K. `VoxelSolver` 自动可解性校验器**：每关发射器队列均经剥壳模拟与 5 槽位前瞻求解验证，100% 保证零氪可解；因重力坍塌或冰晶折射提前清空某色块时，槽位与队列中的冗余同色发射器将**自动连锁清退并化为奖励**，绝不产生废弹卡槽死局。
- **无障碍三重识别规范**：独立色相 + 独立材质光影 + 一键开启几何微符号（`◎ ≈ ◆ ▣ ▲ ✦`）。

### 3. 剥壳寻宝 × 3D 微缩玻璃罩展柜（Diorama Shelf）
每一座体素雕塑中央核心均封存着高精度 3D 微缩藏品（**鎏金招财猫、法式起酥可颂、薄荷旁轴胶片机、琉璃戏莲锦鲤、宇治抹茶急须组、皇室花丝鎏金冠**），通关即永久陈列于 3D 橡木微缩玻璃罩展柜。

### 4. 尊严经济 × 底部防误触二次确认锁
- **6:1 健康经济比**：单关基础 50 金币 + 坍塌与连击奖励，尊严续关仅需 360 金币（且每局附赠 1 次免费共振救场），配合通过坍塌与三连清槽**免费充能解锁的第 6 共振超载槽**。
- **防误触安全区**：三大战术道具（磁吸清槽 / 碎柱爆破 / 智能洗牌）独立置于屏幕最底部安全区，并强制启用 **2.8 秒双次点击确认安全锁**，彻底杜绝误触扣费。

### 5. 移动端 GPU 性能优化架构
- **极低 Draw Call 合批**：全场景体素按四大材质与黄铜锁拆分为仅 **5 个 `MultiMeshInstance3D` 批次**。
- **零开销解析式体素环境光遮蔽（Analytical Voxel Cavity AO）**：利用体素邻域拓扑预计算精确缝隙遮蔽并通过 `INSTANCE_CUSTOM.w` 传入着色器，在手机 WebGL2 上无需昂贵屏幕空间 SSAO 即可还原棚拍级立体质感。
- **GPU 顶点阻尼果冻回弹 & 预分配碎片对象池**：受击果冻抖动完全在顶点着色器按时间戳衰减计算，坍塌与碎裂粒子全程复用对象池，零 GC 卡顿。
- **182KB 子集化开源中文字体**：基于 OFL `Noto Sans CJK SC` 精准裁剪子集，移动端远程秒开。
